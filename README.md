মেথড,সহজ কাজ,ব্যবহারের ক্ষেত্র
$transaction,একাধিক কাজ একসাথে সফল করা।,যখন একাধিক কুয়েরি একটি একক ইউনিট হিসেবে চালানো প্রয়োজন (All or Nothing)।
$queryRaw,সরাসরি SQL লিখে ডেটা আনা।,যখন প্রিসমার ডিফল্ট মেথড দিয়ে জটিল কোনো ডেটা রিড করা সম্ভব হয় না।
$executeRaw,সরাসরি SQL লিখে ডেটা পরিবর্তন করা।,যখন SQL লিখে সরাসরি ডাটাবেসে Update বা Delete করতে হয়।
$connect / $disconnect,ডেটাবেস লাইন চালু বা বন্ধ করা।,কানেকশন পুল ম্যানেজ করতে এবং স্ক্রিপ্ট শেষে ডেটাবেস কানেকশন রিলিজ করতে।
$on,কি কুয়েরি চলছে তা মনিটর করা (Logging)।,ডিবাগিং বা পারফরম্যান্স অ্যানালাইসিসের জন্য কুয়েরি লগ দেখতে।
$extends,প্রিসমার ক্ষমতা বাড়ানো (Custom functions)।,কাস্টম মেথড বা ফিল্ড যোগ করে প্রিসমার ডিফল্ট লজিক আরও শক্তিশালী করতে।
